Bot eChain — Banyak Tab

Mengisi form Pelatihan di eChain dari data yang disiapkan di Avengers. Sekali klik, satu tab terbuka untuk tiap sertifikat. Bot tidak pernah menekan Submit: lampiran PDF dan Submit tetap kamu sendiri.

Pasang sekali saja
  1. Munculkan bilah bookmark browser: Ctrl + Shift + B.
  2. Seret tombol biru ini ke bilah bookmark:   Isi eChain
  3. Atau: lalu buat bookmark baru dan tempel sebagai alamatnya.

Sudah pernah pasang versi lama? Hapus yang lama, pasang yang ini.

Cara pakai
  1. Di Avengers: Personel → buka orangnya → tab Pelatihan. Centang sertifikat yang mau diunggah, tekan “Siapkan terpilih ke eChain”. Antreannya tersalin.
  2. Login VPN lalu eChain seperti biasa.
  3. Klik bookmark Isi eChain sekali → semua tab langsung terbuka, satu per sertifikat.
  4. Di tiap tab: klik bookmark Isi eChain → form tab itu terisi dengan sertifikatnya sendiri.
  5. Periksa isian, pilih file PDF, tekan Submit sendiri.

Pertama kali: Chrome biasanya memblokir banyak tab sekaligus. Klik ikon pop-up yang muncul di ujung kanan address bar → pilih “Selalu izinkan pop-up dan pengalihan” → Selesai. Lalu klik bookmark lagi — tab yang tadi terblokir akan dibuka.

Kalau nomor sertifikat sepertinya sudah ada di eChain, bot memberi peringatan dulu. Unggahan eChain tidak bisa dihapus, jadi hati-hati dengan duplikat.

Data berpindah lewat clipboard karena eChain di balik VPN tidak bisa dihubungi langsung oleh server Avengers. Antreannya disimpan di browser ini (localStorage eChain) sampai semua terisi; judul tiap tab diberi tanda [nomor/total].
